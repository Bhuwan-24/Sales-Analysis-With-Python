   Sales   Data   Analysis (Python & Pandas)

Hi there! This is a data analysis project I built to practice my Python skills. I took 12 months of sales data (simulating a real electronics store) and used Pandas to figure out the best business strategies.

What I wanted to find out

I treated this like a real job assignment. If I were the data analyst for this store, I wanted to answer these specific questions:
  When do we sell the most?(To see seasonal trends).
  Where are our customers?(Which cities buy the most electronics).
  When should we run ads?(To figure out the peak times people are buying).
  What products are popular?(And why?)
  
  Tools I Used
  
  Python: The main language.
  Pandas: I used this for 90% of the work—loading data, cleaning it up, and crunching the numbers.
  Matplotlib: To visualize the answers with charts.
  OS Module: To automatically read all 12 CSV files from the folder at once.
